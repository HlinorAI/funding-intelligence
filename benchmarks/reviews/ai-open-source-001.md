# Benchmark Review: SkyPilot Open-Source AI Infrastructure

## Scope

This public-only case uses the official [SkyPilot repository](https://github.com/skypilot-org/skypilot) and [documentation](https://docs.skypilot.co/). It tests whether visible open-source engineering and a documented GPU workload are kept separate from company eligibility, program access, traction, and current funding need.

## Confirmed public facts

- SkyPilot is an open-source system for running AI workloads across clouds, Kubernetes, and on-premise infrastructure.
- The repository and documentation describe installation, deployment, multi-cloud scheduling, and GPU workloads.
- A working public repository and documentation exist.

## Facts retained as unknown

- Legal entity, company geography, current funding need, revenue, users, and runway.
- Cloud-program account state, prior credits, and provider-specific eligibility.
- A named NVIDIA program champion, partner workload, measurable integration target, and incorporation evidence.
- Current accelerator or startup-program affiliations.

## Expected decision boundaries

Public code and a GPU workload establish technical relevance, but they do not establish corporate eligibility or make a program immediately actionable. For NVIDIA the expected boundary is `VERIFY_FIRST`: the native workload is present, while incorporation and program eligibility remain incomplete.

## Quality signal under test

The engine must recognize strong technical fit without converting repository visibility into company, traction, or program-access evidence.
